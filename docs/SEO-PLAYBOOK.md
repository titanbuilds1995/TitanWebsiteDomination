## 2. Hard rules

1. **Never invent facts.** No fake testimonials, reviews, addresses, acreage totals, deal counts, team
   members, awards, or years in business. If a fact is missing, leave it out or use neutral copy.
2. **Do not touch legal/compliance text** on PrivacyPolicy, TermsConditions, SmsConsent, SmsTerms
   except for SEO metadata via `useSeo`. These pages exist for SMS (10DLC) compliance.
3. **Keep the design language.** Navy (`blue-900`), gold (`#B8956A` / `#D4AF6A`), Cormorant Garamond
   headings, Montserrat body. Reuse existing section patterns in `src/components/home/`.
4. **Every page sets SEO via the hook:** `useSeo({ title, description, path })` from `src/lib/seo.jsx`.
   One `<h1>` per page. Descriptions 120–160 characters.
5. **Build must pass before pushing:** `BASE44_LEGACY_SDK_IMPORTS=true npm run build`.
6. **Pages are auto-registered.** Adding `src/pages/NewPage.jsx` makes it reachable at `/NewPage`.
   `src/pages.config.js` is regenerated by Base44; do not hand-edit it beyond what its header allows.
7. **Routes are case-sensitive and match the file name.** Link with `createPageUrl('PageName')`.
8. **No new dependencies** unless unavoidable. The project already has framer-motion, lucide-react,
   tailwind, shadcn/ui.
9. **Small, reviewable changes.** One or two improvements per run. Plain-English commit messages.
10. **Images:** stock Unsplash images are placeholders. Do not add more stock imagery; prefer no image
    over a generic one. Always set descriptive `alt` text.

## 3. Deployment flow

GitHub `main` → synced to the Base44 Builder automatically → Rodrigo clicks **Publish** in Base44.
Nothing goes live until Publish is clicked, so `main` is safe to push to once the build passes.

In the Base44 dashboard (Marketing → SEO & GEO → Meta tags) **"Automatic titles and descriptions"
must be OFF** and (Advanced settings → Structured data) **"Structured data" OFF**, so the tags in
`index.html` and `useSeo` are what crawlers see. Base44 still serves sitemap.xml and robots.txt.
